# How to download and run?
- Put your main.py file in a new folder, for example a folder with the name "BrowserCursor".
- If you haven't installed python yet, now's the time. Newer python version will work i think - https://www.python.org/
- Download Pyinstaller - https://pyinstaller.org/en/stable/
- Run "pyinstaller main.py" in the BrowserCursor folder, if that doesn't work (it didn't for me) try "python -m PyInstaller main.py" or something like that
- In the "dist" folder, you'll find the exe. Run it, and there you go!

# How to use?
- The default USE button is the <u>divide button on the numpad</u>
- The default EXIT PROGRAM button is the <u>right alt</u>
- When you press the USE button, the cursor will snap to the top of the screen and press left click
- To change the keybinds, you have to change them in the main.py
